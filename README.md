# Gerador de Currículo

Gerador de currículos responsivo para o navegador, publicado no GitHub Pages.

## Funcionalidades

- Dados pessoais e profissionais
- Experiências e habilidades
- Texto automático sobre o candidato
- Três modelos de currículo
- Seleção de cores
- Foto opcional
- Prévia em formato A4
- Exportação por impressão/PDF
- Compartilhamento de resumo pelo WhatsApp
- Salvamento local no navegador
- Chave Pix fixa para apoio voluntário

## Uso

Acesse o site publicado ou abra `index.html` em um navegador.

Os dados permanecem no `localStorage` do navegador. Nenhuma informação é enviada para um servidor pela aplicação.

## Publicação

O projeto pode ser publicado pelo GitHub Pages a partir da branch `main`, usando a raiz do repositório como fonte.
